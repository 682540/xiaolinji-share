# 小凛机 · 资源共享仓库

小凛机「资源集市」的后端。所有资源以普通文件形式存放在本仓库，前端通过 jsDelivr CDN 读取，全程不需要服务器。

## 目录约定

仓库根目录下的**每个文件夹 = 资源集市首页的一个分类**，随手新建即可，前端自动识别，不需要改代码。

每个分类下：

- 一个**子文件夹** = 一条资源（本体文件 + 可选 `说明.txt` + 可选一张封面图）
- 一个**散落文件** = 一条纯文字资源

示例：

```
预设/
├── 日常向预设/
│   ├── 日常向.json      ← 本体（可以多个）
│   ├── 说明.txt         ← 可选，列表里显示摘要
│   └── 封面.jpg         ← 可选，列表里显示第一张图
└── 极简预设.json         ← 散落文件式资源
```

## 怎么投稿

1. **管理员**：直接把文件传到对应分类，提交即可，立即生效。
2. **普通用户**：Fork 本仓库 → 在自己的副本里加文件 → 开 Pull Request → 等管理员合并。

合并后 GitHub Actions 会自动重建 `_index.json`，前端刷新即可看到。

## 注意

- `_index.json` 由 Actions 自动生成，**请不要手改**。
- 单个文件不要超过 20MB（jsDelivr 的硬上限），图片建议压到 300KB 以内。
- 上传前请确认你有权分享这些内容。
